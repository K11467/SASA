**GraphPPIS**（Yuan et al., *Bioinformatics* 2022）—— "Structure-aware protein-protein interaction site prediction using deep graph convolutional network"

它几乎是给你量身定做的：

- **代码、数据、预训练模型全开源**：https://github.com/biomed-AI/GraphPPIS
- **直接显式使用 SASA**：在它的 DSSP 特征（L×14）里，SASA 就是其中一维。你 Project 2 算出来的就可以直接喂进去，甚至可以做"我自己实现的 SASA vs DSSP 的 SASA"对比
- **数据集已经划好**：Train_335 / Test_60 / Test_315 / UBtest_31，省去你最痛苦的数据预处理工作
- **难度刚好**：模型本身就是个 8 层 GCN，单卡几小时能跑完，比 EquiPPIS、GTE-PPIS 这种 SOTA 友好得多

后续 EquiPPIS、AGAT-PPIS、MEG-PPIS、DeepProSite 都沿用了 GraphPPIS 的数据集划分，所以你跑出来的数字可以直接跟一堆论文对比，写报告非常好写。

## 怎么把这个课题做"重"——5 个延展方向（按工作量递增）

**方向 A：SASA 的"质量"研究（最贴近 Project 2）**
你自己的 SASA 算法和 DSSP、FreeSASA、NACCESS 算出来的 SASA 在 PPI 位点预测下游任务上有性能差异吗？不同探针半径（1.4 / 1.6 / 2.0 Å）对预测精度的影响？这是把 Project 2 直接"利用"起来的最自然路径，且有明确的实验对比。

**方向 B：差分 SASA（ΔSASA）作为标签来源**
对一个复合物结构（PDB 里大把），分别算 apo（单链）和 holo（复合物）的 SASA，**ΔSASA > 阈值的残基就是真实结合界面**。用这个去训练自己的预测器，对比"用真实标签 vs 用 ΔSASA 伪标签"。这就把 SASA 从特征升级到了"自监督信号"。

**方向 C：把局部 SASA 几何化**
单残基 SASA 只是个标量，太弱。可以算：每个残基周围 8Å 球内的 SASA 直方图、SASA 梯度方向（朝向溶剂还是朝向核心）、SASA 的多尺度版本（用不同探针半径扫一遍得到一个向量）。这相当于给残基构造一个"局部表面环境指纹"，比单值信息量大得多。

**方向 D：ESM-2 / ESM-3 嵌入 + SASA 多模态融合**（图里说的"多模态"真正版）
用 ESM-2 (650M) 抽序列嵌入（1280 维），和你的几何/SASA 特征拼接，做消融对比"ESM only / SASA only / ESM+SASA"。**这才是 2024-2026 年版的多模态融合**。ESM 嵌入用 HuggingFace 几行代码就能拿到。

**方向 E：用 AlphaFold 结构的鲁棒性测试**
GraphPPIS 在实验晶体结构上训练，你把测试集的结构换成 AlphaFold2/3 预测出来的结构，性能跌多少？SASA 这个特征是不是比序列特征更"扛得住"结构噪声？这个问题 EquiPPIS 论文回答过一部分，但你可以做得更系统，且和 Project 2 完美闭环——因为你需要从 AF 结构上重新计算 SASA。
