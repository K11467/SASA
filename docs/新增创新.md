## 四步升级路线图

---

## Step 1：数据集扩充至500+复合体

**问题**：100个复合体连标准测试集规模都不到（Dset_72只有72个蛋白，但那是*测试集*，训练集通常数千个）。

**解决方案**：修改 `collect_complex_dataset.py`，将 `--count` 默认值改为500，`--candidate-limit` 增至3000，并新增质量过滤条件。

**运行命令**：
```bash
python -m sasa_project.collect_complex_dataset --count 500 --candidate-limit 3000
```

**代码改动**（见 `src/sasa_project/collect_complex_dataset.py`）：
- `--count` 默认值：100 → 500
- `--candidate-limit` 默认值：600 → 3000
- 分辨率过滤：≤3.0Å → ≤2.5Å（更严格，数据质量更高）
- 新增序列长度下限：两条链各至少30个残基（原为20）
- 新增断点续传：跳过已下载的PDB文件

---

## Step 2：加入标准测试集（Dset_186 / PDBtest_315）

**问题**：自定义随机划分无法与Pair-EGRET、MEG-PPIS等方法直接比较指标。

**解决方案**：新增 `scripts/run_benchmark_eval.py` 脚本，下载并处理Dset_186和PDBtest_315标准测试集，在其上跑完整评测流程并输出可与文献对比的指标。

**Dset_186 PDB ID列表来源**：GraphPPIS论文（Sun et al., Bioinformatics 2021）补充材料，共186个蛋白质链，来自非冗余的PPI界面数据集。

**运行命令**：
```bash
python scripts/run_benchmark_eval.py --benchmark dset186 --model-checkpoint saved_model.pt
```

---

## Step 3：新增特征——二面角 + 半球暴露度（HSE）

**问题**：当前特征只有SASA + ESM-2。MGMA-PPIS、MEG-PPIS等方法还使用了骨架二面角（phi/psi）和半球暴露度（HSE），这些特征捕捉局部结构信息。

**解决方案**：修改 `residue_features.py`，新增：
1. **二面角**：phi（φ）= C(i-1)-N(i)-CA(i)-C(i)，psi（ψ）= N(i)-CA(i)-C(i)-N(i+1)，各用sin/cos编码（4维）
2. **半球暴露度（HSE-α）**：以CA-CB向量为分界，统计13Å球内分别落在上/下半球的Cα原子数（2维）

新特征维度：原1282维 → **1288维**（+6维结构特征）

---

## Step 4：升级GCN为等变图神经网络（EGNN）

**问题**：基础GCN不具备旋转不变性——旋转蛋白质结构后预测结果会变化，这在物理上是错误的。2025年所有顶级方法均使用等变GNN。

**解决方案**：在 `train_interface_model.py` 中新增 `EGNNModel` 类，实现E(n)-等变图神经网络（Satorras et al., 2021）的核心算法，纯PyTorch实现，无需额外依赖。

**EGNN核心原理**：
```
m_ij = φ_e(h_i, h_j, ||x_i - x_j||²)        # 消息函数（利用距离而非坐标，保证不变性）
x_i' = x_i + Σ_j (x_i - x_j) · φ_x(m_ij)   # 坐标更新（等变）
h_i' = φ_h(h_i, Σ_j m_ij)                    # 特征更新（不变）
```

**运行命令**：
```bash
python -m sasa_project.train_interface_model --model egnn --feature-set esm_sasa
```

### 模型性能对比（最终结果）

所有实验使用相同随机种子（seed=42），按复合体划分训练/验证/测试集（70/15/15）。

| 模型 | 数据集 | 特征维度 | Test F1 | Test AUROC | Test AUPRC |
|---|---|---|---|---|---|
| **EGNN + ESM+SASA** | 500复合体 | 1282维 | **0.9688** | **0.9922** | **0.9817** |
| **MLP + ESM+SASA** | **500复合体** | **1282维** | **0.8152** | **0.9577** | **0.9099** |
| GCN + ESM+SASA（原） | 100复合体 | 1282维 | 0.6025 | 0.8368 | 0.6156 |
| MLP + ESM+SASA（原） | 100复合体 | 1282维 | 0.6642 | 0.8767 | 0.7389 |
| MLP + ESM only（原） | 100复合体 | 1280维 | 0.6480 | 0.8736 | 0.7242 |
| MLP + SASA only（原） | 100复合体 | 2维 | 0.8754 | 0.9439 | 0.9136 |

**核心发现**：
- 数据规模从100→500，MLP+ESM+SASA的F1从0.6642提升至0.8152（+23%），证明数据量是旧版本性能低的主要原因
- EGNN替换GCN后，Test F1从0.6025提升至0.9688，AUROC从0.8368提升至0.9922
- EGNN的等变性使其能直接从3D坐标学习界面的几何规律

## 局限性说明

### 1. EGNN过拟合

训练集F1=0.9997（近乎完美），验证集F1=0.9200，差距显著。

**根本原因**：当前训练策略为每个复合体图单独做梯度更新（在线学习），350个训练图各自对权重更新一次，相当于给模型350次独立"背诵"机会，导致记忆训练数据。

**更诚实的性能指标**：应以验证集F1=**0.9200**作为模型真实泛化能力的估计，而非测试集的0.9688。

**改进方向**：
- 改为小批量梯度累积（每8个图step一次）
- 增加早停机制（监控val F1）
- dropout从0.2提高至0.4

### 2. 特征-标签相关性泄露

ΔSASA标签本身由SASA计算得出，EGNN输入的3D坐标同样是SASA计算的输入。因此EGNN在理论上可以重新推导标签，导致性能虚高。这一问题在所有使用ΔSASA作为弱监督标签的方法中普遍存在，是本项目方法论框架的固有局限。

**文档建议**：在报告结果时注明"ΔSASA弱监督场景下的上界估计"，并建议未来使用独立生物实验注释数据集（如BioLiP）进行外部验证。

### 3. 数据集规模仍不足

500个复合体在领域内仍属小规模（DIPS-Plus有42,112个）。建议后续扩展至2,000+复合体以获得更稳定的泛化性能。

### 4. 标准基准上未完成端到端评测

Dset_186的ΔSASA标签已生成（39,505条残基），但尚未提取对应的ESM-2嵌入并完成模型推断，因此目前仍无法与Pair-EGRET、MEG-PPIS在同一基准上直接比较指标数值。
