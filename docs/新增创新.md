# 已完成的创新升级

## 当前状态

项目已从课程级 SASA 示例升级为可复现的弱监督 PPI 位点预测管线：

```text
500 个双链复合物
-> Delta-SASA 弱监督标签
-> ESM-2 650M embedding
-> 1287 维 ESM / geometry 严格特征
-> EGNN 主模型 / cross-chain EGNN 分析模块
-> Dset_186-local 与 PDBtest_315-local 外部评测
```

## 已完成升级

| 升级项 | 当前结果 |
|---|---|
| 数据扩展 | 500 个训练复合物，95,005 个目标链残基 |
| ESM 模型 | `facebook/esm2_t33_650M_UR50D`，1280 维 |
| 结构特征 | SASA、坐标、phi/psi、HSE、疏水性 |
| 图模型 | EGNN 与 partner-chain attention EGNN |
| cutoff 消融 | 6 / 8 / 10 / 12 A，8 A 最均衡 |
| 标准评测 | Dset_186-local 与 PDBtest_315-local 已完成 |
| 工程质量 | 自动化测试、GBK 控制台兼容、产物清单 |

## 主模型结果

| 模型 | 特征维度 | Test F1 | Test AUROC | Test AUPRC |
|---|---:|---:|---:|---:|
| EGNN / ESM + geometry（strict primary） | 1287 | **0.7745** | **0.9322** | **0.8421** |
| EGNN / apo + ESM + geometry（strict ablation） | 1288 | 0.7787 | 0.9348 | 0.8514 |
| EGNN / apo+holo + ESM + geometry（diagnostic） | 1289 | 0.8948 | 0.9768 | 0.9497 |

## 外部 benchmark

| 数据集 | 复合物 | 残基 | Strict EGNN F1 | Holo-aware cross-chain diagnostic F1 |
|---|---:|---:|---:|---:|
| Dset_186-local | 158 | 39,505 | 0.3529 | 0.6439 |
| PDBtest_315-local | 314 | 65,119 | 0.3040 | 0.6816 |

GraphPPIS 资产引用使用 Yuan et al.。`-local` 表示按当前仓库结构可用性和链质量规则处理后的本地子集。
