# 基于自研SASA特征与深度蛋白质语言模型的弱监督蛋白质界面预测系统

## 1. 故事主线总览：从经典生物物理问题到现代AI微观建模

本项目的核心叙事逻辑可以概括为：**“从一个经典的生物物理计算问题出发，通过引入弱监督学习范式攻克标签匮乏困境，最终利用多模态特征融合与图神经网络实现结构感知的微观生物功能预测。”**

这一主线将原本孤立的几何面积测算作业（Project 2）深度激活，使其演变为整个深度学习流水线（Pipeline）中不可或缺的**数据特征提取器**与**弱监督标签生成器**。

## 2. 核心技术模块详析

### 2.1 故事起点：经典生物物理问题（SASA计算）
* **生物学背景**：溶剂可及表面积（Solvent Accessible Surface Area, SASA）是结构生物学与生物物理学中的一个经典概念，最早由 Lee & Richards 于 1971 年提出。它定义了水分子（通常简化为半径 1.4Å 的球体）在蛋白质三维结构表面滚动时，球心所形成的轨迹表面积。
* **传统局限**：在传统计算生物学中，SASA 仅作为一个标量输出，用于评估蛋白的溶解度或折叠状态。在 AI 视角下，纯粹的手工特征工程（如纯 SASA $\\rightarrow$ SVM 分类器）属于 2015 年前的经典范式，信息密度极低，极易被端到端的大模型基线（Baseline）击溃。

### 2.2 核心突破：物理规则转化为弱监督信号（$\\Delta$SASA 伪标签生成）
为了将经典物理问题接入现代机器学习任务，我们需要解决“大规模相互作用界面数据标注高昂”的痛点。
* **物理状态转换**：
    * **Apo 状态（单体状态）**：蛋白质链单独存在，界面残基完全暴露于溶剂中，$SASA_{\\text{apo}}$ 较大。
    * **Holo 状态（复合物状态）**：两条或多条蛋白质链相互结合，由于空间遮挡，界面残基的暴露面积骤减，$SASA_{\\text{holo}}$ 变小。
* **差分物理量（$\\Delta$SASA）**：
    $$\\Delta SASA = SASA_{\\text{apo}} - SASA_{\\text{holo}}$$
* **AI视角（弱监督学习 / Weak Supervision）**：
    物理法则告诉我们，$\\Delta SASA$ 显著大于 0 的残基必然位于结合界面上。因此，我们无需依赖昂贵的生物实验，直接利用自研的 SASA 算法计算差分值，并通过设定阈值自动生成二分类伪标签（Pseudo-labels）：
    $$Y_i = \\begin{cases} 1, & \\text{if } \\Delta SASA_i > \\text{Threshold} \\\\ 0, & \\text{otherwise} \\end{cases}$$
    这成功将一个几何计算任务转化为了**自监督/弱监督的数据准备模块**。

### 2.3 表征升级：高维语义与多模态特征融合
单一的物理特征（SASA 标量）无法承载复杂的机器学习任务，必须引入微观进化与序列语义信息。
* **蛋白质大语言模型（ESM-2）**：作为蛋白质领域的 "BERT"，ESM-2 通过在大规模无标注序列上进行掩码语言建模（Masked Language Modeling），其浅层和中层网络天然编码了氨基酸的进化、二级结构及微观物理化学倾向。通过预训练网络提取残基级嵌入向量（Residue-level Embedding, $\\mathbf{x}_i^{\\text{esm}} \\in \\mathbb{R}^{1280}$）。
* **多模态融合（Multi-modal Fusion）**：
    将高维序列语义（ESM-2）与显式几何暴露特征（自研 $SASA_{\\text{apo}}$）进行横向拼接（Concatenation），构建出兼具“进化基因”与“当前三维空间构象”的多模态节点特征空间：
    $$\\mathbf{h}_i = [\\mathbf{x}_i^{\\text{esm}} \\parallel \\text{SASA}_{\\text{apo}, i} \\parallel \\text{Residue\\_Properties}_i]$$
    *注意：为了防止数据泄漏（Data Leakage），预测器的输入特征只能包含单体状态的 SASA，而用于生成 Label 的 $\\Delta SASA$ 绝对不能作为输入。*

### 2.4 架构落地：结构感知的图卷积网络（GCN）
蛋白质本质上是一个非欧几里得空间的三维几何图结构，非常适合用图神经网络（GNN）建模。
* **图构建（Graph Construction）**：
    * **节点（Nodes）**：每一个氨基酸残基为一个节点 $v_i$，其初始特征为多模态向量 $\\mathbf{h}_i$。
    * **边（Edges）**：计算残基中心原子（通常为 $C_\\alpha$）之间的欧氏距离，若距离 $d(i, j) < 8\\text{Å}$，则在节点 $i$ 和 $j$ 之间建立一条边，捕捉局部三维微环境。
* **任务定义**：PPI 界面预测被严格定义为**图神经网络中的节点二分类（Node Classification）任务**。
* **模型传播机制**：
    利用多层图卷积网络（GCN），使每个残基能够自适应地聚合其在空间邻域内其他残基的序列与几何信息，最终通过一个多层感知机（MLP）和 Sigmoid 函数输出该残基属于界面的概率：
    $$\\hat{y}_i = \\text{Sigmoid}(\\text{GCN}(\\mathcal{G}, \\mathbf{H}))$$

## 3. 推荐实验与消融设计（Ablation Study）

为了使项目具备严谨的 AI 论文结构，报告中必须包含以下实验论证：

### 3.1 特征消融实验（证明多模态的必要性）
评估不同输入特征对最终节点分类指标（AUROC / AUPRC / F1-Score）的影响：
1.  **SASA Only**：仅输入单体几何特征，验证传统特征的性能瓶颈。
2.  **ESM-2 Only**：仅输入预训练语言模型表征，验证纯序列信息在缺乏空间结构感知时的表现。
3.  **ESM-2 + SASA (Ours)**：验证多模态融合后，几何空间信息是否能与序列进化信息形成优势互补。

### 3.2 弱监督标签阈值敏感性实验
探究伪标签生成规则中的超参数（$\\Delta SASA$ 阈值）对模型性能的影响：
* **小阈值（如 0.5 Å²）**：标签宽松，正样本（界面）比例高，但引入大量噪声，导致模型 Precision 下降。
* **大阈值（如 5.0 Å²）**：标签严苛，仅保留核心核心结合位点，正样本极少，导致样本极度不平衡，模型 Recall 下降。
* **分析结论**：寻找最佳平衡点（通常为 1.0 Å² 或 2.0 Å²），体现对弱监督伪标签质量控制（Data Quality Control）的深度思考。

## 4. 答辩/报告亮点总结（如何讲好这个AI故事）

1.  **物理启发式弱监督**：我们没有停留在几何计算本身，而是把经典的生物物理规则（SASA 差值）巧妙转化为了机器学习的**自监督信号（弱监督标签生成器）**，解决了生物领域结构数据标注难的痛点。
2.  **多模态图表征学习**：有机融合了非结构化文本序列预训练表征（ESM-2）与结构化三维空间拓扑特征（SASA + 3D Graph），展示了全栈的**图深度学习（Graph Deep Learning）**管线设计。
3.  **完美的工程闭环**：Project 2 的自研核心代码不是废件，它既是整个数据流的物理特征提取起点，又是校验伪标签生成的黄金标准，实现了基础算法向深度学习系统的华丽蜕变。
